# VoxKnesset

The kit does not include VoxKnesset audio.

```bash
./local/download_voxknesset.sh --data "${DATA_ROOT}"
./local/prepare_voxknesset.sh --data "${DATA_ROOT}"
```

Raw files go under `${DATA_ROOT}/voxknesset/raw_data`; prepared manifests and
trials go under `${DATA_ROOT}/voxknesset/prepared`.

Core scenario: `voxknesset`.

Follow the upstream VoxKnesset terms.
