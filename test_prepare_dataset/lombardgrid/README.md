# Lombard Grid

The kit does not include Lombard Grid audio.

```bash
./local/download_lombardgrid.sh --data "${DATA_ROOT}"
./local/prepare_lombardgrid.sh --data "${DATA_ROOT}"
```

Raw files go under `${DATA_ROOT}/lombardgrid/raw_data`; prepared manifests and
trials go under `${DATA_ROOT}/lombardgrid/prepared`.

Core scenario: `lombardgrid_lombard`.

Follow the upstream Lombard Grid terms.
