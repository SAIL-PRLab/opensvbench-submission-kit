# Upload

1. Open `https://opensvbench.xyz/submit/model`.
2. Enter the model name and the requested description fields.
3. Upload the zip produced by `./scripts/04_generate_submission_zip.sh`.
4. Check the result page after processing. Complete full-core submissions can be
   reviewed for the public ranking.

The uploaded archive must contain `submission.json` and the CSV files under
`scores/`. Do not upload embedding caches, preview files, or generation reports.
